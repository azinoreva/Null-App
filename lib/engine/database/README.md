# `lib/engine/database` — Encrypted Database Layer

The local persistence layer: Drift (SQLite ORM) over an **encrypted** SQLite
database, plus the table and DAO source files.

## Files

| File | Purpose |
|---|---|
| `init_db.dart` | `DatabaseInitializer` — creates/opens the encrypted database. Generates a random **AES-256 key** on first install, stores it in `FlutterSecureStorage`, and unlocks the database with `PRAGMA hexkey` (SQLite3MultipleCiphers / `sqlcipher_flutter_libs`). Verifies the key persists before continuing. The rest of the app doesn't know encryption exists. |
| `app_database.dart` | `AppDatabase` (extends `_$AppDatabase`) — registers all 14 tables and 14 DAOs via the `@DriftDatabase` annotation. Schema `version 3`, with migrations:
  - v1 → v2: adds `Contacts.publicKey`
  - v2 → v3: adds `Messages.decryptedMessage`
  
  Also enables `PRAGMA foreign_keys = ON` on create/upgrade/open, and drops stale indexes that no longer back any query. |
| `app_database.g.dart` | **Generated** Drift code (companions, data classes, database/DAO base classes). Do not edit — regenerated by `dart run build_runner build`. |
| `tables/` | [See `tables/README.md`](tables/README.md) — the 14 table definitions. |
| `queries/` | [See `queries/README.md`](queries/README.md) — the 14 DAOs that all app code reads/writes through. |

## How it's wired up

- `main.dart` calls `DatabaseInitializer.initialize()` at startup and injects
  the resulting `AppDatabase` into Riverpod by overriding
  `appDatabaseProvider` in the `ProviderScope`.
- The `TaskEngine` (see `lib/engine/engine.dart`) uses *the same* database
  instance from a background isolate to claim and execute queued tasks.
- File location: `<app-support-dir>/database/null.db`.

## Regenerating generated code

After editing any table or DAO file, run:

```sh
dart run build_runner build
```

Do not hand-edit files ending in `.g.dart`.

## Naming notes

Dart-reserved words are stored under alternate column names
(`_status`, `_timestamp`, `_name`, `retrys`). See
[`tables/README.md`](tables/README.md) for the full list.
